# Evaluation plan

Before making quality claims, create a versioned set of at least 20 questions: direct lookup, cross-document synthesis, multi-hop, table lookup, ambiguous, out-of-scope, unanswerable, and conflicting-source cases. Record expected document/page IDs. Report recall@k, MRR, citation precision/recall, human-reviewed faithfulness, correct abstention rate, latency, and configuration versions. No benchmark scores are claimed by this starter.
